Traduction prête · moteur LibreTranslate

LibreTranslate est libre et l’API publique sélectionnée est utilisée sans clé. Quand le mode traduit est activé, seuls les segments finalisés — jamais l’audio — sont envoyés à translate.argosopentech.com. C’est un service public communautaire : disponibilité, vitesse, quotas et traitement des textes dépendent de son exploitant. Consultez aussi le projet LibreTranslate.

02 / Budget estimatif

Coût Deepgram

Calcul indicatif avec les tarifs publics Nova-3 et diarisation (0,002 $/min). Le nouveau compte peut recevoir 200 $ de crédit ; vérifiez votre solde et la facturation avant un stream prolongé. Les prix peuvent changer. Tarifs Deepgram · Console / solde.

Les estimations supposent un seul flux mono capturé, Nova-3 et la diarisation activée. La durée réelle varie selon les tarifs, le crédit éligible et l'utilisation.

03 / Crédit & autonomie

Solde et heures restantes estimés

Deepgram expose le solde en USD, pas un quota d'heures fixe ; les heures affichées sont une conversion selon le mode choisi. Le solde peut être lu avec une clé ayant les droits de gestion. Sinon, saisis le crédit restant depuis la console. Le compteur soustrait le coût estimé des sessions de cette application depuis la dernière actualisation ; l’usage Deepgram effectué ailleurs n’est pas suivi automatiquement.
